
Step1: installing Webscoket in laravel project
  composer require beyondcode/laravel-websockets
Step2: publish migration file for storing statistics
  php artisan vendor:publish --provider="BeyondCode\LaravelWebSockets\WebSocketsServiceProvider" --tag="migrations"
Step3: Migrate. But before migrating, update .env file as follows:

   => update .env file
     - APP_NAME ="" app name is used as identifier by websocket
    - APP_URL ="";  //do not use localhost because it worsk fines but no Statistics
    - BROASDCAST_DRIVER = pusher,

     PUSHER_APP_ID=1312272 (or whatever value you set)
     PUSHER_APP_KEY=780bc0f81cba4c28118a (or whatever value you set)
     PUSHER_APP_SECRET=330244c53d84af48fc46 (or whatever value you set)

  => update config/app.php file to allow 
            -- BroadcastServiceProvider class. NOTE that "Illuminate\Broadcasting\BroadcastServiceProvider::class" works well, but "App\Providers\BroadcastServiceProvider::class" does not work
            -- EventServiceProvider class
   
  => check and ensure that config/websockets.php configuration is correct, esp. the "apps" section      
  => now run this command: php artisan migrate

Step4: Installing "pusher-php-server". NOTE for php 8, cannot user pusher-php-server version 3. So user pusher-php-server version 4  
 
  run command: composer require pusher/pusher-php-server "~4.0" => if cannot run this command do as follows
    - open package.json in root foler
    - add this line to "requires" section 
          "require": {
               "pusher/pusher-php-server": "^4.0"
                 }
         and then run command: "composer update"


Step5: check out the Laravel-websocket if can starts correctly
       Depending on APP_URL setting in .env file, but it is usually through url like this:
       127.0.0.1:8000/laravel-websockets
